# ⌨️ Typing Speed Test

## About the Project
Typing Speed Test is a simple and interactive website built using HTML, CSS, and JavaScript. It helps users measure their typing speed, accuracy, and typing errors within a limited time.

## Features
- 30-second typing test
- Real-time Words Per Minute (WPM) calculation
- Typing accuracy percentage
- Incorrect character tracking
- Countdown timer
- Progress bar
- Best score saved using Local Storage
- Restart and try-again options
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start typing in the text box to begin the test.

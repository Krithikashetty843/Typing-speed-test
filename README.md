# ⌨️ Typing Speed Test

## About the Project

Typing Speed Test is a simple, interactive website built using HTML, CSS, and JavaScript. It helps users measure their typing speed, accuracy, and typing errors within a selected time limit.

## Features

- Choose a test duration: 15, 30, 60, or 120 seconds
- Different typing passages for each duration
- Real-time Words Per Minute (WPM) calculation
- Typing accuracy percentage and error tracking
- Countdown timer and progress bar
- Best score saved using Local Storage
- Final results showing WPM, accuracy, and errors
- Recent test history saved in the browser
- Restart and try-again options
- Back-to-home button
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Choose a test duration and click **Start Test**.
5. Type the displayed passage before the timer ends.

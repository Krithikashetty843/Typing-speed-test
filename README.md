# ⌨️ Typing Speed Test

## About the Project

Typing Speed Test is a simple and interactive website built using HTML, CSS, and JavaScript. It helps users measure their typing speed, accuracy, and typing errors within a selected time limit.

## Features

- Four test durations: 15, 30, 60, and 120 seconds
- Three difficulty levels: Easy, Medium, and Hard
- 12 combinations of duration and difficulty
- Different typing passages for each combination
- Real-time Words Per Minute (WPM) calculation
- Typing accuracy percentage and error tracking
- Countdown timer and progress bar
- Best WPM score saved using Local Storage
- Final results showing WPM, accuracy, and errors
- Recent test history saved in the browser
- Light and Dark mode with saved theme preference
- Restart and Try Again options
- Back to Home button
- Responsive design for desktop and mobile devices
- Button hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Choose a test duration and difficulty level.
5. Click **Start Test**.
6. Type the displayed passage before the timer ends.
